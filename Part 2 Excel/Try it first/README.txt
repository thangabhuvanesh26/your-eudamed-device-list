Try it first: sample answers

These three files are made-up EUDAMED answers. All devices in them are made up.
Use them to check that the Excel list works on your computer before you use EUDAMED.

1. Set up Excel as in step 7 of README.md in the folder Part 2 Excel.
2. In the line ResponseFolder = "...", put the path of this folder
   (Part 2 Excel\Try it first), not the folder above it.
3. Click Done, then Home > Close & Load.

You should see 17 columns and 12 rows: 11 Registered, 1 Discarded.

Registered needed 2 files here: Registered answer 01.xml says numberOfPages 2,
so Registered answer 02.xml is in this folder too. Discarded needed 1 file.

This README.txt is ignored: Excel reads only the .xml files.

Afterwards, change the path to your own answers folder (see README.md in the
folder Part 2 Excel, "Try Excel with sample answers"). Then do the checks of
step 8 in that README with your real answers.
